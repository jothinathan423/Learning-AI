# Comparisons

Side-by-side comparisons of tools, techniques, and concepts that are commonly confused or
weighed against each other. Each guide centers on a comparison table, with a short intro and a
closing "when to choose which" section.

- **[LLM vs Traditional ML](./LLM-Vs-Traditional-ML.md)** — narrow, task-specific models versus
  general-purpose language models.
- **[Dense vs Sparse Embeddings](./Dense-Vs-Sparse-Embeddings.md)** — neural semantic vectors
  versus classical lexical (TF-IDF/BM25) representations.
- **[RAG vs Fine-Tuning](./RAG-Vs-Fine-Tuning.md)** — retrieving fresh context at answer time
  versus baking knowledge into model weights.
- **[Agent vs Workflow](./Agent-Vs-Workflow.md)** — dynamic, LLM-driven control flow versus
  fixed, developer-defined orchestration.
- **[Prompt Template vs System Prompt](./Prompt-Template-Vs-System-Prompt.md)** — per-request
  message structure versus persistent session-level behavior.
- **[LangChain vs Semantic Kernel](./LangChain-Vs-Semantic-Kernel.md)** — two major frameworks
  for building LLM-powered applications.
- **[Vector DB Comparison](./Vector-DB-Comparison.md)** — Qdrant, Chroma, pgvector, Pinecone,
  and Weaviate on hosting model, indexing algorithm, filtering support, and ideal use case.
- **[OpenAI vs Anthropic API](./OpenAI-Vs-Anthropic-API.md)** — conceptual differences in
  message shape, tool calling, structured output, and context windows.
