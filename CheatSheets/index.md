# Master Cheat Sheets

Cross-week, topic-oriented quick-revision references. Where a weekly `CheatSheet.md` covers one
week's material, each file here pulls a single theme together across every week that touches it
— plus general industry knowledge where the 7-week curriculum doesn't fully cover the topic.

| Cheat Sheet | Covers |
|---|---|
| [LLM](./LLM.md) | Tokens, context windows, decoding, model families, hallucination — the master LLM fundamentals reference |
| [Prompt Engineering](./Prompt-Engineering.md) | Prompt anatomy, zero/few-shot, chain-of-thought, structured output, general prompting best practices |
| [Embeddings](./Embeddings.md) | Word/sentence embeddings, static vs. contextual, embedding model comparison, similarity metrics |
| [Vector Database](./Vector-Database.md) | Qdrant/Chroma/Pgvector and the wider landscape, ANN indexes, metadata filtering, decision guide |
| [RAG](./RAG.md) | Chunking, retrieval, hybrid search, reranking, grounded generation, evaluation metrics — the consolidated RAG reference |
| [AI Agents](./AI-Agents.md) | Agent loop, ReAct, tool design, stop conditions, memory, agent vs. workflow, framework landscape |
| [LangChain](./LangChain.md) | LangChain/LangGraph concepts, core components, LCEL, when to use a framework vs. hand-rolled code |
| [MCP](./MCP.md) | Model Context Protocol — architecture, primitives, how it relates to tool calling, use cases |
| [OpenAI SDK](./OpenAI-SDK.md) | Chat Completions vs. Responses API shape, function/tool calling, structured outputs, streaming, key parameters |
| [Fine-Tuning](./Fine-Tuning.md) | What fine-tuning is, when to use it vs. RAG/prompting, LoRA/PEFT, RLHF, data requirements, tradeoffs |
