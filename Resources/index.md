# Resources

Curated, per-week further-reading lists — official docs, research papers, blogs, videos, books,
and GitHub repos — organized into Beginner / Intermediate / Advanced tiers for each week's
topics. These are supplementary: nothing here is required to complete a week, and none of it
replaces the Topics/Notes/CheatSheet content itself.

No fabricated links are used anywhere in these lists. Where a resource is named without a
hyperlink, search for it by the title/author given — that's deliberate, since stable, real
resource names age better than guessed URLs.

## Weekly Resource Lists

- [Week 1 — Foundations](/Resources/Week-01) — language models, tokens, cost, context windows,
  embeddings, sampling, model families, hallucination.
- [Week 2 — Prompting & Tool Calling](/Resources/Week-02) — prompt anatomy, chain-of-thought,
  structured output, tool/function calling, guardrails.
- [Week 3 — Retrieval & RAG](/Resources/Week-03) — dense retrieval, chunking, vector databases,
  grounded generation.
- [Week 4 — Debugging Retrieval](/Resources/Week-04) — BM25, hybrid search, reranking, query
  rewriting, HyDE, retrieval metrics.
- [Week 5 — Error Analysis](/Resources/Week-05) — traces, sampling, open coding, error taxonomy,
  prioritization.
- [Week 6 — Evals](/Resources/Week-06) — eval sets, assertion checks, LLM-as-judge, G-Eval,
  RAGAS.
- [Week 7 — Agent Loops](/Resources/Week-07) — the agent loop, ReAct, tool design, agent memory,
  LangChain/LangGraph.
